# AI Marketing Platform

This project is an AI-powered marketing automation platform built with n8n, a LangChain AI Agent, Ollama LLM, and Tavily Internet Search.

## Key Capabilities

- AI Telegram assistant for users and leads.
- Voice-message processing with speech-to-text.
- AI responses generated by a local Ollama model.
- Real-time web search through Tavily.
- Per-user conversation memory in PostgreSQL.
- Administrator notifications for incoming leads and messages.

## Features

### Telegram AI Chatbot

The Telegram assistant can qualify leads, provide customer support, and help with marketing requests.

### Voice Message Support

Voice messages are downloaded from Telegram, converted to text by Whisper or OpenAI transcription, and passed to the AI agent.

### AI Agent

The core AI layer uses the `qwen3.5:9b` Ollama model. It routes requests to tools, uses Tavily search for current information, and applies the assistant system prompt.

### Facebook Comments and Messages Auto-Reply

`workflow/Facebook-comments-auto-reply.json` monitors Facebook post comments and private messages, replies through the Facebook Graph API, stores interactions in PostgreSQL, and forwards notifications to Telegram.

Requirements:

- A Facebook Page access token and app webhook subscription.
- A public n8n webhook URL that Facebook can reach.
- Matching webhook verification tokens in Facebook and n8n.
- Configured `POSTGRES_*`, `OLLAMA_*`, and `TAVILY_*` settings.

After import, replace embedded page IDs, chat IDs, and tokens before activating the workflow. Do not commit access tokens, and follow Facebook rate limits and moderation policies.

### Web Search Tool

Tavily provides real-time web search as an AI-agent tool for answering up-to-date questions.

### Memory System

PostgreSQL stores conversation history per user in `n8n_chat_memory`, enabling contextual and durable responses. Database credentials are configured through environment variables.

### Admin Notification System

Incoming messages can be forwarded to administrator and technical-support Telegram chats with user details, the original message, the AI response, and a reply target.

### Telegram Bridge

`telegram_bridge` is a standalone FastAPI service that lets platform components send a message to a Telegram bot through an authorized user account and receive the bot's reply. It runs with the main Docker Compose stack at `http://localhost:8000`.

- One-time Telegram authorization is required before startup.
- `POST /send` accepts `{"text": "..."}` and returns `{"answer": "..."}`.
- The Telethon session is persisted in `telegram_bridge/sessions/` and mounted into the container.

See [docs/telegram-bridge.md](docs/telegram-bridge.md) for setup, API details, response handling, and security guidance.

## Setup and Deployment

### Prerequisites

- Docker and Docker Compose.
- PostgreSQL 16.
- n8n.

### Environment Configuration

Create a `.env` file based on `.env.example`:

```env
POSTGRES_USER=n8n
POSTGRES_PASSWORD=your_strong_password
POSTGRES_DB=n8n_chat_memory

N8N_HOST=your-domain
N8N_PROTOCOL=https
WEBHOOK_URL=https://your-domain/
```

### Local Startup

Use the interactive PowerShell scripts from the repository root:

1. Open PowerShell in this folder.
2. Run `./start.ps1`.
3. Confirm the prompts for Docker, ngrok, Ollama, Whisper, and n8n startup.
4. Wait for the n8n health check to return `200 OK`.
5. Open the displayed n8n URL, or use `http://localhost:5678` if ngrok is unavailable.
6. Run `./status.ps1` at any time to check Docker, Ollama, and ngrok.

Useful commands:

- `./status.ps1` shows Docker, Ollama, and ngrok status.
- `./stop.ps1` stops Whisper, n8n, PostgreSQL, ngrok, and Ollama.
- Logs are written to `logs/`.
